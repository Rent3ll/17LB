# Паспорт выпуска

## 1. Общие сведения
- **Кейс:** DOC-17
- **Версия:** 1.5.0-rc1
- **Пакет:** app-1.5.0-rc1.zip
- **Исходный коммит:** DEMO-COMMIT-015-NOT-A-REAL-GIT-ID *(Примечание: учебный маркер, не является реальным Git-хешем)*
- **Статус готовности:** Не готов к выпуску (требуется устранение блокеров и проведение испытаний).

## 2. Цель выпуска и состав
- **Цель:** Внедрение версии 1.5.0 с поддержкой схемы данных S2 и миграцией M015.
- **Состав:** Приложение app-1.5.0, скрипты миграции M015.

## 3. Среда и зависимости
- **ОС:** Linux x64
- **Среда исполнения:** Python 3.11 или 3.12
- **СУБД:** PostgreSQL 15 или 16
- **Свободное место:** Минимум 2048 МиБ.

## 4. Параметры конфигурации
Секреты в паспорт не включены. Передача секретов осуществляется отдельным разрешенным механизмом.

| Имя параметра | Назначение | Место подстановки |
|---|---|---|
| `APP_PORT` | Порт приложения (значение: 8081) | Конфигурационный файл / ENV |
| `DB_HOST` | Хост БД (значение: lab-db-01) | Конфигурационный файл / ENV |
| `DB_NAME` | Имя БД (значение: service_lab) | Конфигурационный файл / ENV |
| `ATTACHMENTS_DIR` | Директория вложений (значение: /srv/service_lab/attachments) | Конфигурационный файл / ENV |

## 5. Миграция и данные
- **Миграция:** M015 (расширяющая, добавляет необязательную категорию).
- **Схема:** Переход с S1 на S2.
- **Откат:** Старая версия 1.4.2 может читать S2 до включения функции `category_required`. После появления новых записей возврат требует согласованного преобразования данных.

## 6. Ограничения и известные проблемы
- Контроль целостности пакета **не подтвержден** (отсутствует вычисленный хеш).
- Последнее испытание восстановления из резервной копии **не проводилось** (в пакете данных нет).
- Тестирование производительности **не проводилось** (`not_run`).
